Welcome to JARVIX

This appears to be the first time you've launched JARVIX.

JARVIX orchestrates a sequential pipeline of AI coding agents to execute a software development lifecycle. Each agent is a specialized role (Architect, Programmer, Reviewer, etc.) that reads context files, performs its task, and writes output to a shared project folder.

Before creating a project, you'll need at least one agent in your library. Let's start by creating an agent.

A boilerplate agent file will be created and opened in your default editor. The file includes comments explaining each section.

How to Test Your App

Test your app by using it normally. While doing so, you can take screenshots using Shift + S. This will capture your whole screen.

⚠ Beware of any personal or secret information appearing on screen when taking a screenshot. The screenshot captures everything visible on your display.

After pressing Shift + S, a text field will appear here in Jarvix. Write a comment describing the issue you just captured, then press OK to save the screenshot and comment together. You can then take another screenshot.

When you are finished testing, press Done — Write Report.
